# World Cup 2026 Forecast Dashboard

A probabilistic forecast lab for the 2026 FIFA World Cup. Publishes pre-match win/draw/loss probabilities, simulates tournament outcomes, and tracks model performance as real results come in.

## Project structure

```
WC-Project/
├── data/
│   ├── raw/          # Source CSVs — never edited directly
│   └── processed/    # Cleaned outputs generated by scripts
├── notebooks/        # Exploratory analysis and cleaning work
├── src/              # Finalized scripts
└── ROADMAP.md
```

## Data sources

- **results.csv** — International football results 1872–2026 ([martj42](https://github.com/martj42/international_results))
- **goalscorers.csv** — Goal and scorer data per match
- **shootouts.csv** — Penalty shootout outcomes
- **former_names.csv** — Historical team name mappings

## Stack

| Layer | Tech |
|-------|------|
| Frontend | Next.js + TypeScript |
| Charts | Recharts / ECharts |
| Backend | Python + FastAPI |
| Modeling | pandas, scikit-learn, XGBoost |
| Deploy | Vercel (frontend) + Render/Fly.io (backend) |
